常见问题

无法读取角度：请确认运动与健身权限已允许，并在训练页重新开始一次训练。使用 AirPods 时确认耳机支持头部运动数据。

购买后没有解锁：请打开网络，进入“设置 → 关于仰观 → 恢复购买”。权益由 App Store 交易状态决定。

如何取消订阅：在 App 的“管理订阅”中跳转到 Apple 订阅管理页。取消后仍可使用至当前计费周期结束。

如何删除记录：进入“设置 → 数据管理”，选择清空训练历史或本机使用记录。

训练结束提醒：训练自动结束或你手动结束后，会显示训练结果弹窗。
